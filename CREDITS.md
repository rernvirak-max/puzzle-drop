# Photo credits

Puzzle Drop ships five photographs of Cambodia. They are real photos from
Wikimedia Commons, not generated images. Each file in `public/photos/` was
resized so the long edge is about 1080 pixels and saved as JPEG. The fish
amok photograph is 800 pixels wide because that is the original file; it was
not enlarged.

The game center-crops each photo into a square while you play. That crop is
done in the browser and is not baked into the files.

Custom pictures chosen with **Use my photo** stay on the device and are not
listed here.
