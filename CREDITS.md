# Photo credits

Puzzle Drop ships 49 photographs of Cambodia and Khmer life. Every file in `public/photos/` is a real photograph from Wikimedia Commons, saved as WebP with the long edge at about 1080 pixels. The game crops each photo in the browser when it cuts a picture into tiles.

A photo chosen with **Use my photo** stays on the device and is not listed here.
